# 🔥 Spark Cloud · 火花云续 — 抖音自动续火花(小白版教程)

> 每天到点自动给抖音好友发一条消息,把「火花」和连续聊天天数一直养下去。
> **你只需要:一台电脑(或一台云服务器)+ 一部手机 + 一个抖音账号。不用懂任何代码。**

---

## 📋 目录(先看这个,再选一条路)

| 路线 | 难度 | 适合谁 | 在哪一步操作 |
|---|---|---|---|
| ⭐ **A. Docker Compose** | 简单 | 有 Linux 服务器 / NAS / 面板机 | 一条命令 |
| ⭐ **B. Windows 本地运行** | 简单 | Windows 用户首选(不用 Docker) | 双击两个脚本 |
| **C. Linux 云服务器** | 中等 | 想要 7x24 小时稳定运行 | 一条命令 |
| **D. GitHub Actions 免费云端** | 中等 | 不想买服务器 | 网页配一次 |

> 💡 **小白建议**:Windows 用户直接走 **B(本地)**;有服务器/NAS/面板机走 **A(Compose)**;想全托管再上 **C / D**。

---

## 🧰 需要准备什么

- ✅ 一台 **Windows / Mac / Linux** 电脑(能上网、能开浏览器)
- ✅ 一部装了 **抖音 App** 的手机(用于扫码登录)
- ✅ 一个 **抖音账号**(强烈建议先用小号试跑!)
- ✅ 注册一个 **GitHub 账号**(免费,只有路线 D 需要)

## ⭐ 路线 A:Docker Compose 部署(Linux 服务器 / NAS / 面板机)

> Windows 电脑不需要 Docker——本地运行请走路线 B。

### 第 0 步:准备 Docker(已装可跳过)

Ubuntu/Debian 一条命令安装:
~~~bash
curl -fsSL https://get.docker.com | bash
~~~
NAS / 面板机(群晖、1Panel、宝塔等)一般自带 Docker,直接下一步。

### 第 1 步:拿到项目文件

**方式一(推荐,简单):**
1. 打开项目 GitHub 页面 → 点绿色 **Code** 按钮 → **Download ZIP**;
2. 解压到服务器任意目录,例如 `/opt/spark-cloud`。

**方式二(需要装过 Git,没装过可看路线 D 里的安装教程):**
~~~bash
git clone <你的仓库地址> spark-cloud
~~~

### 第 2 步:一条命令启动

~~~bash
cd /opt/spark-cloud
docker compose up -d --build
~~~
(或等价的 **`bash deploy/docker-up.sh`**,它会顺便生成随机访问令牌写进 `.env`)

第一次构建镜像需要几分钟(国内已内置镜像加速,不会卡在下载)。完成后:
- 网页地址:`http://服务器IP:8000`
- 访问令牌:看 `.env` 里的 `SPARK_TOKEN`(**记下来**,后面要用)

> 💡 **想换端口?** 改 `.env` 里 `SPARK_WEB_PORT=9000` 再重跑启动命令。
> 💡 **想换镜像源?** `.env` 里加 `APT_MIRROR=mirrors.tuna.tsinghua.edu.cn`(清华)或 `mirrors.ustc.edu.cn`(中科大),`PIP_INDEX_URL` 同理。
> 💡 **更新版本?** 重新上传代码后再执行一次 `docker compose up -d --build`,`data/` 数据不会丢。

### 第 3 步:登录抖音(网页扫码,不用装任何东西)

1. 浏览器打开 `http://127.0.0.1:8000`;
2. 如果页面要令牌,输入第 2 步记下的那串字符;
3. 左侧点 **「凭证」** → 点 **「开始扫码登录」**;
4. 页面出现二维码后,**用手机抖音 App 扫一扫**(或截图后用抖音扫一扫-相册识别);
5. 手机确认后,网页提示 **「登录成功」** 就搞定了。

> ⚠️ 偶尔会触发抖音的二次安全验证(刷脸),页面会出现新二维码,再扫一次即可。

### 第 4 步:勾选好友 + 设置时间(以后每天自动)

1. 左侧点 **「好友」** → 点 **「同步联系人」**(等十几秒,别关页面);
2. 列表会按**火花天数从高到低**排序,点 **「一键勾选火花好友」**;
3. 点 **「保存勾选」**;
4. 左侧点 **「定时」** → 设置**每天发送时间**(默认 21:00 就行)→ 点 **「保存设置」**;
5. ✅ 完成!从明天起,到点它就会自动给好友发消息续火花。

**日常维护**:服务器/NAS 开着就行(容器已设开机自启)。登录态过期了?重复第 3 步扫码即可。

## ⭐ 路线 B:Windows 本地运行(不装 Docker)

1. 解压项目,双击 **`scripts\1.提取登录态.bat`**:
   - 第一次会自动建环境、装依赖(几分钟,别关窗口);
   - 然后弹出浏览器 → **手机扫码登录抖音** → 自动保存登录态;
2. 双击 **`scripts\3.启动管理后台.bat`**:会自动打开 `http://127.0.0.1:8000`;
3. 然后和路线 A 的**第 3、4 步一样**:扫码或上传登录态 → 同步勾选好友 → 设置时间;
4. **保持黑色窗口开着**,电脑就会每天自动续火花;关机/关窗口 = 暂停。

> 想立刻手动跑一次?双击 `scripts\2.立即运行.bat`,可选手动发送 / 演练 / 仅同步。

## 🐧 路线 C:Linux 云服务器(7x24 稳定运行)

**买服务器**:阿里云/腾讯云「轻量应用服务器」,Ubuntu 22.04 或 24.04,选**离你近的城市**(IP 归属地一致不容易被抖音风控)。记好 root 密码。

**部署(一条命令):**

1. 用 SSH 工具(如 Windows 自带终端)连上服务器;
2. 把项目弄到服务器上——推荐 git clone,不会上传也能搞定:

   <details>
   <summary><b>📖 手把手:怎么把项目弄到服务器(点开)</b></summary>

   **方式一:git clone(推荐,服务器上一条命令搞定)**

   在刚才连上服务器的窗口里逐行执行(把"你的用户名/仓库名"换成自己的):

   ~~~bash
   sudo apt update && sudo apt install -y git
   git clone https://github.com/你的用户名/仓库名.git /opt/spark-cloud
   ~~~

   - **公开仓库**:直接就下载完了,结束;
   - **私有仓库**:会提示输入用户名和密码——用户名填 GitHub 用户名,密码处要粘贴**访问令牌**(不是登录密码!):GitHub 网页右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token,勾上 `repo` 权限生成,复制粘贴到密码处(粘贴时不显示,直接回车);
   - 克隆到 `/opt/spark-cloud` 是为了和后面的部署命令对上。

   **方式二:ZIP 上传(不想碰 git 的)**

   1. GitHub 仓库页面 → 绿色 **Code** 按钮 → **Download ZIP**,解压到电脑上;
   2. 装 [WinSCP](https://winscp.net)(免费),新建连接:协议 SFTP,主机填服务器 IP,用户 `root`,密码填你买服务器时设的;
   3. 左边本地窗口拖到右边服务器的 `/opt/` 下,把解压出的文件夹改名为 `spark-cloud`,完成。

   </details>
3. 执行:
   ~~~bash
   sudo bash deploy/deploy.sh
   ~~~
4. 脚本会自动:装依赖 → 装浏览器内核 → 注册开机自启;
5. 完成后显示 **`http://服务器IP:8000`** 和**访问令牌**;

**注意**:到云控制台「防火墙/安全组」放行 **8000 端口 (TCP)**,否则网页打不开。

之后浏览器打开网址 → 输入令牌 → 网页扫码登录 → 勾选好友 → 设置时间,和路线 A 完全一样。

## 🚀 路线 D:GitHub Actions 免费云端(不买服务器,电脑可关机)

原理:续火本体跑在 GitHub 的免费服务器上,每 30 分钟自动检查一次;数据(登录态/好友/台账/通知配置)AES 加密后存进你自己的**私有仓库**,每轮跑完自动回写提交,循环持久化。

### 开通步骤(一次性)

1. **本地配置好一切**:先按路线 B 启动本地后台 → 扫码登录抖音 → 同步勾选好友 → 设置发送时间(「定时」页,每个账号可不同)→ 配好通知渠道;
2. **一键上云**:双击 **`scripts\6.一键seal推送.bat`**,之后全程自动:
   - 自动读取(或问你一次)口令 → 自动 seal 加密数据;
   - 没装 git / GitHub CLI 会自动用 winget 装好;
   - **弹浏览器登录 GitHub**(黑窗口让你按回车 → 浏览器打开 GitHub,输入它显示的一次性代码)——这就是唯一的"登录界面";
   - **自动在你的账号下新建私有仓库 `spark-cloud`**(已存在就直接复用),并自动把口令写进仓库 Secrets(`DATA_KEY`)、启用 Actions;
   - 推送完成。以后每次双击全自动、零输入。
   习惯命令行的话也可以手动 seal:
   ~~~powershell
   $env:DATA_KEY = '自定义一个口令'          # 记牢,恢复数据也要用它
   .venv\Scripts\python.exe scripts\gh_run.py seal   # 生成 vault\data.enc
   ~~~
3. **(可选)手动方式**:6 号脚本已自动完成"建仓库 + 推代码 + 配密钥",想手动折腾才看下面——**推到 GitHub 私有仓库**(必须 Private!)没装过 Git 的看这里:

   <details>
   <summary><b>📖 手把手:安装 Git 并上传项目(点开)</b></summary>

   **方式一:GitHub Desktop(图形界面,全程点点点,推荐小白)**

   1. 打开 **[desktop.github.com](https://desktop.github.com)** → 下载 → 安装 → 用你的 GitHub 账号登录;
   2. 左上角 **File → Add local repository** → 选项目文件夹(如 `C:\spark-cloud`);
   3. 弹窗提示"not a repository"?点 **create a repository here**(名称随便,保持 **Private** 勾选);
   4. 左下角填写摘要(如 `init`)→ 点 **Commit to main**;
   5. 点顶部 **Publish repository** → ⚠️ **取消勾选 "Keep this code private" 才会公开——保持勾选私有状态!** → 点 Publish;
   6. 完成。以后每次改完数据(如重新 `seal`),同样:填摘要 → Commit → Push,云端就更新了。

   </details>

   上传完成后打开仓库页面确认代码都在(⚠️ **确认是 Private 标记**);
   - **配密钥**(脚本没配成时手动加):仓库 Settings → Secrets and variables → Actions → New repository secret,Name 填 `DATA_KEY`,Value 填第 2 步的口令;
4. 到 **Actions → streak → Run workflow** 手动跑一次验证,之后全自动。

### 它是怎么跑的

- 每 30 分钟一拍:解密数据 → 北京时间判断每个账号到没到自己的计划时间 → 到点的账号用无头浏览器真实执行 → 台账回写 → 加密提交回仓库(同日自动去重,不会重发);
- 跑完自动发**结果通知**(见下方「微信推送绑定」);GitHub 定时有 ±20 分钟随机延迟,属正常;
- 计划时间不用改 cron——账号在「定时」页设置几点,Actions 就到点执行。

### 登录过期怎么办 / 改配置怎么办

收到 `login_expired` 推送或想改文案/好友时:
1. 本地按路线 B 启动后台 → 重新扫码 / 改配置;
2. 再执行一次 `seal`(记得先 `$env:DATA_KEY='你的口令'`)→ push,云端即恢复。

### 如实交代的限制

- GitHub 出口是海外数据中心 IP,抖音风控概率比家宽/同城服务器高,建议小号试跑;
- **没有网页面板、没有微信指令菜单**(无常驻进程);改任何配置都是本地改 → seal → push;
- 仓库必须 **Private**,数据虽已加密也不要公开。

> 仓库另有两个工作流:`ci.yml` 每次 push 自动编译检查;`deploy.yml` 手动触发 SSH 到你自己的服务器执行 `docker compose up -d --build`(需配 `DEPLOY_SSH_*` 等 Secrets,服务器需能被 GitHub 访问)。

## 📣 微信推送绑定(所有路线通用,一次绑定到处收)

绑好后续火结果会实时推到你微信:**send_ok**(本轮成功 N 人)/ **send_fail**(失败名单+原因)/ **login_expired**(登录过期提醒)。

1. 本地启动后台(路线 B)→ 网页 **设置 → 通知渠道** → 选 **「微信直连(扫码绑定)」**;
2. 点 **「生成二维码」** → **微信扫一扫** → 手机上点确认;
3. ⚠️ **关键一步**:在微信里给这个机器人**随便发一条消息**(如"1")——微信规定机器人只能推给"先发过消息"的用户,不发这条收不到推送;
4. 点 **「测试推送」**,微信收到即绑定成功;
5. **路线 A/B/C**:到这里就完了,配置存在服务器上直接生效,机器人在线能自动刷新会话;
   **路线 D(GitHub Actions)**:⚠️ **别选微信直连,选 Bark / Server酱 / Webhook**。微信直连的推送会话有时效,本地机器人不在线就没人刷新它,GitHub 那边隔天再发就会报 `ret=-2 prepare failed`。用 Bark/iOS、Server酱/微信服务号或自定义 webhook,纯 HTTP 无凭据,云端永久可用;

> 绑定凭据存在 `data\wx_state.json`(已随 data 目录被 gitignore 保护,不会裸传 GitHub)。

## ❓ 小白常见问题

**Q: 端口被 8000 占用,或者我想换个端口?**
- 本地/服务器运行:**直接在网页顶部点「端口」按钮修改**,填新端口后点「保存并重启」,浏览器会自动跳到新地址(写入 `.env` 的 `SPARK_PORT`,无需改文件);
- 也可以手动改项目目录里的 `.env` 文件:
  - Compose 部署:加/改一行 `SPARK_WEB_PORT=你想要的端口`(例如 `9000`),重跑启动命令(网页里修改端口对容器不生效,因为容器内端口被 compose 固定);
  - 本地/服务器运行:改 `SPARK_PORT=你想要的端口`,重启服务。
- 改完后用新端口访问,例如 `http://127.0.0.1:9000`。

**Q: 网页打不开?**
- Compose 路线:确认容器在运行(`docker ps`);
- 服务器路线:确认防火墙放行了 8000 端口;
- 本地路线:确认黑窗口还开着。

**Q: 页面显示「加载失败: Failed to fetch」?**
意思是网页已经打开,但连不上后台服务(网络请求失败)。请检查:
- 你是不是**直接双击了 index.html 文件**?那样一定失败!请用脚本启动后,通过 `http://127.0.0.1:8000` 打开(直接双击文件时页面会给出红色提示);
- 本地路线:确认黑窗口还开着、没有报错退出;
- Compose 路线:确认容器在运行(`docker ps`),或重新执行 `docker compose up -d --build`;
- 端口被占用:黑窗口报 "Address already in use" 时,说明 8000 端口被别的程序占用了,先关掉那个程序再试。
> 页面打开后如果服务中途挂掉,顶部会出现红色横幅「无法连接服务器」,服务恢复后会自动重试并消失。

**Q: 二维码一直不出来?**
冷启动要 20~40 秒;超过 1 分钟点「取消」重新开始。还不行就去看「日志」页的报错。

**Q: 提示"操作频繁/安全验证"?**
抖音的风控,脚本检测到会自动停止本轮,不会硬来。缓解:服务器选同城节点、先小号试跑、别开太多浏览器。

**Q: 登录态多久过期?**
几天到几周不等。过期后到「凭证」页重新扫码即可,不用重新部署。

**Q: 任务卡住了?**
点网页右上角红色的**「停止」**按钮,一键重置。

**Q: 我什么都没勾选,点"立即续火花"报错?**
先去「好友」页同步联系人 → 勾选 → 保存,再运行。
